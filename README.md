# 📱 Mobile Sales Analysis Dashboard

## 1. Project Title / Headline

📱 Mobile Sales Analysis Dashboard

An interactive Power BI dashboard designed to analyze mobile sales performance, customer purchasing behavior, transaction trends, and brand performance across different cities and time periods.

---

## 2. Short Description / Purpose

The Mobile Sales Analysis Dashboard is a business intelligence solution developed in Power BI to provide comprehensive insights into mobile sales data. The dashboard enables users to monitor sales performance, analyze customer ratings, evaluate payment methods, and identify top-performing brands and locations through interactive visualizations and KPI tracking.

This dashboard is intended for business analysts, sales managers, retailers, and decision-makers seeking data-driven insights to improve sales strategies and operational performance.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

• 📊 Power BI Desktop – Primary platform for dashboard development and visualization.

• 📂 Power Query – Used for data cleaning, transformation, and preparation.

• 🧠 DAX (Data Analysis Expressions) – Used to create KPIs, calculated measures, and business metrics.

• 🔗 Data Modeling – Relationships established between sales, customer, and transaction-related data.

• 📈 Interactive Visualizations – Maps, line charts, bar charts, KPI cards, funnel charts, and pie charts.

• 📁 File Formats – .pbix for development and .png for dashboard previews.

---

## 4. Data Source

Source: Mobile Sales Dataset

The dataset contains information related to mobile phone sales transactions, including:

• Mobile Brands and Models

• Sales Revenue

• Quantity Sold

• Customer Ratings

• Payment Methods

• Transaction Details

• City-wise Sales Performance

• Daily and Monthly Sales Trends

The data is structured to support sales analysis, customer behavior analysis, and business performance monitoring.

---

## 5. Features / Highlights

### • Business Problem

Mobile retailers generate large volumes of sales data every day. However, understanding sales performance across locations, products, and customer segments can be difficult without proper visualization.

Important business questions include:

• Which cities generate the highest sales?

• Which mobile brands perform best?

• How do sales fluctuate over time?

• Which payment methods are most preferred by customers?

• How do customer ratings impact business performance?

---

### • Goal of the Dashboard

The primary goal of this dashboard is to:

• Monitor overall sales performance using KPIs.

• Analyze sales trends across months and weekdays.

• Identify top-performing mobile brands and models.

• Understand customer satisfaction through ratings analysis.

• Evaluate payment method preferences.

• Support business decisions with interactive insights.
